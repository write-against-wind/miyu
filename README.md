# 密屿 · 本地密码本

一个中文 Windows 桌面密码本。账号数据保存在本机，使用主密码加密，支持加密备份。无需注册账号或连接云服务。

## 开始使用

从 [GitHub Releases](https://github.com/write-against-wind/miyu/releases/latest) 下载 `Miyu-Vault-版本号-x64.exe`，双击即可使用。便携版无需安装 Node.js 或开发依赖。GitHub 的 Source code 下载包仅包含源码。

1. 第一次打开时，设置并确认至少 8 个字符的主密码。建议使用独特的长短句。
2. 点击“添加账号”，填写名称、网址、用户名和密码。可以直接生成随机密码。
3. 使用搜索、分类和收藏查找账号。密码默认隐藏，点击眼睛查看，点击复制按钮复制。
4. 在“备份与恢复”中定期导出 `.miyu` 加密文件，并放到另一个可靠的存储设备。

**主密码无法找回。** 忘记后无法解密密码库或对应备份。第一次使用建议先用测试账号熟悉备份和恢复。

## 功能

- 创建、编辑、删除网站账号；搜索名称、账号、网址和备注。
- 工作、个人、财务、社交、其他分类，以及收藏。
- 随机密码生成器，可选择长度和字符类型。
- AES-256-GCM 加密整个密码库，名称、网址、账号和备注也不会以明文保存。
- 1 / 5 / 15 / 30 分钟自动锁定，默认 5 分钟。最小化、Windows 锁屏或休眠时也锁定。
- 复制的内容在 30 秒后或锁定时清理；如果剪贴板已被其他内容替换，则保留新内容。
- 显示的账号密码 20 秒后自动隐藏，切换账号、窗口失焦时立即隐藏。
- 加密备份、恢复备份、更改主密码。
- `Ctrl+K` 聚焦搜索；`Ctrl+L` 立即锁定；`Esc` 关闭对话框。

## 数据与备份

真实密码库位于 `%APPDATA%\MiyuVault\passwords.miyu`，通常为 `C:\Users\你的用户名\AppData\Roaming\MiyuVault\passwords.miyu`。应用“设置”中会显示准确路径。自动锁定偏好保存在同目录 `settings.json`，不含密码。

程序文件和账号数据分开保存。移动便携版 `.exe` **不会**移动密码库；重装系统或换电脑前请导出备份。在新电脑创建一个密码库，然后在“备份与恢复”中导入备份即可。

恢复会替换当前所有账号，需明确勾选确认，建议恢复前先导出当前数据。恢复时输入**导出备份时的主密码**；恢复成功后，当前密码库继续使用当前主密码。更改主密码不会修改以前导出的备份，所以旧备份仍需旧主密码。

## 开发

Windows x64，Node.js **22.12 或以上**，npm。当前使用 Electron 44.4.3 和原生 HTML/CSS/JavaScript；加密核心仅依赖 Node.js 标准库，没有远端数据库和 CDN。

Git 仓库只保存源码、测试、文档和依赖清单；便携版在 Releases 中下载。开发、运行桌面测试或打包前，先执行 `npm ci` 恢复开发依赖，磁盘占用会相应增加。依赖与构建缓存均可重新生成，无需长期保留。

```powershell
npm ci
npm start
npm test
npm run test:e2e
npm run build
```

安装和首次打包需要联网下载官方依赖与构建工具；应用正常运行不需要联网。构建产物放在 `dist/`。便携版本无需另装 Node.js。当前构建未配置代码签名证书。

`启动密屿.cmd` 和 `npm start` 会优先使用已安装的开发运行时；没有开发依赖时则启动 `dist/` 中的便携版。

## 项目结构

```text
src/main.cjs          窗口、IPC、系统锁定、剪贴板、文件对话框
src/preload.cjs       窄范围的桌面接口
src/core/vault.cjs    密钥派生、加解密、原子写入、数据校验
src/settings.cjs      自动锁定偏好
src/renderer/        中文界面
tests/vault.test.cjs  核心安全与持久化测试
scripts/e2e.cjs       Electron 桌面端到端测试
assets/              应用图标
```

测试使用独立临时密码库和虚构账号，不访问真实数据。桌面测试隔离剪贴板，并生成 `test-results/setup.png`、`vault.png` 和 `e2e-report.json`。

## 安全设计与边界

- scrypt（N=131072、r=8、p=1）结合随机 32 字节盐派生 256 位密钥；每次写入使用独立随机 12 字节 nonce 和 16 字节 GCM 认证标签。格式与参数也经过认证。
- 主密码不写入文件。锁定时清零密钥 Buffer、清除会话数据和界面中的秘密；不会把密码存到浏览器 localStorage。
- 写入先落到同目录临时密文文件，同步到磁盘后替换正式文件；错误密码、损坏或无效备份不会替换现有数据。
- 限制备份大小和派生参数，校验解密后的记录；单实例、写入队列和会话代际检查避免并发写入、锁定与异步操作之间的混乱。
- Electron 启用沙箱和上下文隔离，界面禁用 Node.js；校验 IPC 来源、禁止远端请求和页面跳转，仅加载应用自带资源。发行版关闭 Node 环境变量与调试入口。

这是可继续开发的本地应用，尚未经独立安全审计。加密主要保护静态文件；无法防止已控制电脑的恶意软件读取键盘、屏幕或解锁时的内存。JavaScript 字符串也无法保证从物理内存或系统分页文件彻底擦除。自动清理不保证清除 Windows 剪贴板历史、固定项目或第三方剪贴板管理器的副本。

实现参考：[Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security)、[Node.js 加密 API](https://nodejs.org/api/crypto.html)。
